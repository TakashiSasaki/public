# update-efu.py 仕様書

## 1. 概要
指定された開始ディレクトリから再帰的にディレクトリを探索し、特定のUUIDを持つ**既存の**EFUファイル (`<uuid>.efu`) を見つけた場合、そのディレクトリ以下のファイル構成情報を当該EFUファイルに記録（更新）するツールです。

> [!IMPORTANT]
> 本ツールは**既存のEFUファイルを更新すること**を目的としています。
> 対象となる `<uuid>.efu` ファイルが存在しないディレクトリに、新規にEFUファイルを作成することはありません。

## 2. 入力パラメータ
スクリプト実行時に以下のオプション引数を受け取ります。

1.  **`--uuid`** (`str`): EFUファイルを識別するためのID（例: `my-index`）。
    -   対象ファイル名: `<uuid>.efu`
2.  **`--start-dir`** (`path`): 探索を開始するルートディレクトリ。

## 3.処理ロジック

### 3.1. メイン探索プロセス
1.  **開始ディレクトリ**から探索を開始します。
2.  ディレクトリツリーを再帰的にトラバースします。
3.  各ディレクトリにおいて、`<uuid>.efu` という名前のファイルが存在するか確認します。
4.  **`<uuid>.efu` が見つかった場合**:
    -   そのディレクトリを「**EFUルート**」とみなします。
    -   EFUルート以下のファイル・ディレクトリ情報を収集し、`<uuid>.efu` を更新します（詳細は「3.2. EFU更新プロセス」参照）。

### 3.2. EFU更新プロセス (サブセット探索)
あるディレクトリで `<uuid>.efu` が見つかった場合、そのディレクトリを起点として以下のルールで情報を収集します。

1.  **収集対象**:
    -   起点ディレクトリ以下のすべてのファイルとディレクトリ。
2.  **除外条件 (再帰停止)**:
    -   探索中のサブディレクトリ内に、**同じ名前の `<uuid>.efu` が存在する場合**：
        -   **そのサブディレクトリ以下はトラバースしません。**
        -   代わりに、そのサブディレクトリにある `<uuid>.efu` ファイル自体（およびその親ディレクトリ情報）のみを、現在のEFUファイルに「ファイル」として記録します。
        -   これは、ネストされたEFU管理領域（サブプロジェクト等）の情報を、親のEFUに重複して展開させないための仕組みです。
3.  **出力**:
    -   収集したファイルリストを、起点ディレクトリにある `<uuid>.efu` に書き込みます（Everything EFU形式: CSV）。
    -   **更新ロジック (追記/上書き)**:
        -   既存の `<uuid>.efu` が存在する場合、その内容を読み込みます。
        -   **検証**: ファイルが空であるか、または正しいCSV形式であることを確認します。
            -   **不正な形式の場合**: 更新を行わず、エラーを出力してスキップします（ファイルの破壊を防ぐため）。
        -   **Filename** (パス) をキーとして、既存のエントリと今回スキャンしたエントリをマージします。
        -   今回スキャンされたファイル/ディレクトリ: 新しい情報（Last Seen含む）で上書きします。
        -   今回スキャンされなかったファイル/ディレクトリ (削除されたもの等): **既存のエントリをそのまま残します**。
        -   結果として、EFUファイルには過去に存在したファイルの情報も残り続け、ファイルサイズは単調増加します。

## 4. 挙動例

ディレクトリ構造:
```text
root/
  my-uuid.efu  (A)
  file1.txt
  subdir1/
    file2.txt
  subdir2/
    my-uuid.efu (B)
    file3.txt
```

**処理結果**:
- **(A) `root/my-uuid.efu` に記録される内容**:
    - `root/my-uuid.efu`
    - `root/file1.txt`
    - `root/subdir1/file2.txt`
    - `root/subdir2/my-uuid.efu`  <-- (B)のEFUファイル自体は記録される
    - (`root/subdir2/file3.txt` は記録**されない**)

- **(B) `root/subdir2/my-uuid.efu` に記録される内容**:
    - (別途探索プロセスで更新される場合)
    - `root/subdir2/my-uuid.efu`
    - `root/subdir2/file3.txt`

## 5. Everything EFU形式 (CSV) の仕様
収集した情報は、以下のヘッダーを持つCSV形式で `<uuid>.efu` に保存します。

- **ヘッダー行**: `Filename,Size,Date Modified,Date Created,Attributes,Last Seen`
- **エンコーディング**: UTF-8 (BOM付き推奨)

### 5.1. 各カラムの定義
| カラム名 | 説明 | 備考 |
| :--- | :--- | :--- |
| **Filename** | ファイルまたはディレクトリのフルパス | |
| **Size** | ファイルサイズ (バイト) | ディレクトリの場合は通常空、または0 |
| **Date Modified** | 最終更新日時 | Windows FILETIME形式 (1601年1月1日からの100ナノ秒間隔) |
| **Date Created** | 作成日時 | Windows FILETIME形式 |
| **Attributes** | ファイル属性フラグ | ディレクトリの場合は `16` (0x10) を指定 |
| **Last Seen** | 情報取得日時 | ISO8601形式 (Everythingでは無視される) |

> [!NOTE]
> Windows FILETIMEは、Pythonの `os.path.getmtime()` で得られるUnixタイムスタンプから変換して記録する必要があります。
