# update-efu.py 仕様書

## 1. 概要
指定された開始ディレクトリから再帰的にディレクトリを探索し、特定のUUIDを持つEFUファイル (`<uuid>.efu`) を見つけた場合、そのディレクトリ以下のファイル構成情報を当該EFUファイルに記録（更新）するツールです。

## 2. 入力パラメータ
スクリプト実行時に以下の引数を受け取ります。

1.  **UUID** (`str`): EFUファイルを識別するためのID（例: `my-index`）。
    -   対象ファイル名: `<uuid>.efu`
2.  **開始ディレクトリ** (`path`): 探索を開始するルートディレクトリ。

## 3.処理ロジック

### 3.1. メイン探索プロセス
1.  **開始ディレクトリ**から探索を開始します。
2.  ディレクトリツリーを再帰的にトラバースします。
3.  各ディレクトリにおいて、`<uuid>.efu` という名前のファイルが存在するか確認します。
4.  **`<uuid>.efu` が見つかった場合**:
    -   そのディレクトリを「**EFUルート**」とみなします。
    -   EFUルート以下のファイル・ディレクトリ情報を収集し、`<uuid>.efu` を更新します（詳細は「3.2. EFU更新プロセス」参照）。

### 3.2. EFU更新プロセス (サブセット探索)
あるディレクトリで `<uuid>.efu` が見つかった場合、そのディレクトリを起点として以下のルールで情報を収集します。

1.  **収集対象**:
    -   起点ディレクトリ以下のすべてのファイルとディレクトリ。
2.  **除外条件 (再帰停止)**:
    -   探索中のサブディレクトリ内に、**同じ名前の `<uuid>.efu` が存在する場合**：
        -   **そのサブディレクトリ以下はトラバースしません。**
        -   代わりに、そのサブディレクトリにある `<uuid>.efu` ファイル自体（およびその親ディレクトリ情報）のみを、現在のEFUファイルに「ファイル」として記録します。
        -   これは、ネストされたEFU管理領域（サブプロジェクト等）の情報を、親のEFUに重複して展開させないための仕組みです。
3.  **出力**:
    -   収集したファイルリストを、起点ディレクトリにある `<uuid>.efu` に書き込みます（Everything EFU形式: CSV）。

## 4. 挙動例

ディレクトリ構造:
```text
root/
  my-uuid.efu  (A)
  file1.txt
  subdir1/
    file2.txt
  subdir2/
    my-uuid.efu (B)
    file3.txt
```

**処理結果**:
- **(A) `root/my-uuid.efu` に記録される内容**:
    - `root/my-uuid.efu`
    - `root/file1.txt`
    - `root/subdir1/file2.txt`
    - `root/subdir2/my-uuid.efu`  <-- (B)のEFUファイル自体は記録される
    - (`root/subdir2/file3.txt` は記録**されない**)

- **(B) `root/subdir2/my-uuid.efu` に記録される内容**:
    - (別途探索プロセスで更新される場合)
    - `root/subdir2/my-uuid.efu`
    - `root/subdir2/file3.txt`
