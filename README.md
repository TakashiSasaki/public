# my_uuid_folder

## Project Structure

This repository is a small Rust `cdylib` crate that exposes a Windows COM class factory and a virtual shell folder implementation.

### Tree (top-level, relevant files)

```
.
├── .gitignore
├── Cargo.lock
├── Cargo.toml
└── src
    └── lib.rs
```

### Files and Directories

- `.gitignore`
  - Ignores `target/` build artifacts and `commit_message.txt`.

- `Cargo.toml`
  - Crate metadata and build settings.
  - Declares `crate-type = ["cdylib"]` for a Windows-loadable DLL.
  - Declares dependencies on `windows` and `windows-core`.

- `Cargo.lock`
  - Dependency lockfile generated by Cargo.

- `src/lib.rs`
  - Main library source.
  - Defines `CLSID_MY_FOLDER` GUID.
  - Implements `IShellFolder`, `IPersist`, and `IPersistFolder` stubs (mostly `E_NOTIMPL`) for a virtual folder.
  - Implements `IClassFactory` and exports `DllGetClassObject` and `DllCanUnloadNow` for COM activation.

- `target/` (ignored)
  - Cargo build outputs (binaries, intermediate artifacts).

- `commit_message.txt` (ignored)
  - Local commit message notes (not tracked).
