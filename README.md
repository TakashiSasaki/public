# TakashiSasaki/public

このリポジトリは GitHub Pages で `public.moukaeritai.work` を公開するためのルートリポジトリです。本リポジトリは、その他のすべての開発ブランチをサブモジュールとして統合して管理する特殊な構成となっています。

## リポジトリの構造（サブモジュール構成）

* **ベースブランチ**: このリポジトリのメイン（公開対象）ブランチは `public.moukaeritai.work` です。
* **サブモジュール配置**: このブランチ以外のすべてのリモートブランチ（`master` などの一部の例外を除く）は、そのブランチ名と同じ名前のディレクトリとしてルート直下にサブモジュールとして配置されます。
* 例: `pictogram` ブランチは、当リポジトリ内の `./pictogram` ディレクトリとして配置されています。

開発者やシステムは、各サブディレクトリ内で該当のプロジェクト/ツールの開発作業を行うことができます。

## サブモジュールの同期 (`sync_submodules.ps1`)

リモートリポジトリ（`origin`）に新しいブランチが追加された場合や、ローカルにクローンした直後などで新しいブランチのサブモジュール構成を同期したい場合には、ルート直下に配置されている `sync_submodules.ps1` スクリプトを使用します。

### 使用方法

PowerShell またはターミナルを開き、リポジトリのルートディレクトリから以下のコマンドを実行してください。

```powershell
# 通常の同期実行（リモートの最新ブランチを取得し、不足しているサブモジュールを自動追加）
.\sync_submodules.ps1

# ドライラン（実際には追加せず、どのブランチが追加されるかを確認する場合）
.\sync_submodules.ps1 -DryRun
```

### スクリプトの動作概要
1. `.tmp` ディレクトリを一時ファイル領域として確保します（Gitの追跡対象外）。
2. `git fetch origin` を実行してリモートの最新情報を取得します。
3. `origin` のリモートブランチ一覧を取得します。
4. ローカルですでにサブモジュールとして構成されているブランチの一覧と比較します。
5. リモートには存在するがローカルでまだサブモジュール化されていないブランチを検出し、自動的に `git submodule add` コマンドを発行してルート直下に配置します。
6. ※ `public.moukaeritai.work` および `master` ブランチ等、管理上不要なブランチはスクリプト内で自動的に無視されます。
