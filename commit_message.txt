Remove legacy repository subtree and temporary analysis files

This commit cleans up the repository after the successful integration of 
features from the legacy version:

1.  **Removed `git-local-repo-viewer-old/`**: This directory was temporarily 
    added via `git subtree` to facilitate the comparison and integration 
    of advanced branch relationship logic and UI refinements.
2.  **Removed `diff.txt`**: Temporary file used for analyzing differences 
    between the old and new codebases.

All valuable logic and assets (including `app_icon.png` and enhanced 
relationship detection) have been fully integrated into the main 
`src/branch_detect/` directory in previous commits.
